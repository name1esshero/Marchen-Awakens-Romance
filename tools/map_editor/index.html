MAR map editor

Tile layers · raw attributes · existing event arguments

Start the editor with make map-editor (or py tools/map_editor/server.py on Windows), then open the full localhost URL printed in that terminal. This page needs the Python server.

Visible layers

Choose a tile below.

Click to paint; drag for a stroke. Right-click picks a tile or attribute. Ctrl+Z / Ctrl+Y undo and redo. Ctrl+S saves.

Coordinates are in 8×8 tiles.

Tile artwork comes from the editable PNGs. Saved layout JSON changes placement, palette banks, and flips. Attribute values remain numeric until their meanings are verified.

Event calls

The map's same-name script is selected when present.

Projects this call onto the current map. It does not simulate script execution or show every active region.

CODE order is not execution order. This edits literal integers in existing calls. Dynamic expressions, new calls, warps, and trigger meanings are not yet decoded. Unsupported scripts remain read-only.
