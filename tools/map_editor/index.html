MAR map editor

Tile layers · collision attributes · decoded events · field connections

Start the editor with make map-editor (or py tools/map_editor/server.py on Windows), then open the full localhost URL printed in that terminal. This page needs the Python server.

Visible layers

Choose a tile below.

Green marks procedural connection classes (400–499 and 5400–5499). Other colors distinguish raw values; they do not mean walkable or blocked. Elevation and trigger meanings remain unknown.

Wheel over the map to zoom from 3.125% to 4× around the pointer. Fit whole map shows every tile. Right-click picks; Ctrl+Z / Ctrl+Y undo and redo; Ctrl+S saves.

Coordinates are in 8×8 tiles.

Tile artwork comes from the editable PNGs. Saved layout JSON changes placement, palette banks, and flips. Attribute values remain numeric until their meanings are verified.

Script sprite resources

Play previews literal SprInit, SprChg, SprSet, SprMove, SprSync, and SprFree calls in CODE order. NCD frame durations drive animation. Branches and unresolved register operands are reported and skipped. Drag literal sprite placements and hit rectangles to edit them.
